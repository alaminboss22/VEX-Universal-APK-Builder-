What works right now?

Navigation, theme switching, basic ZIP file selection checks and interface previews.

What still needs to be built?

Secure user authentication, PHP API endpoints, database tables, server-side ZIP validation, isolated Android build workers, build queue, real-time logs and APK download storage.

Important security note

Never put database passwords, FTP credentials, signing keys or API secrets in frontend JavaScript. Keep secrets on the server and in GitHub Actions Secrets.
